# JustGo

JustGo is a clothing and wardrobe management web application built using React and Node.js.

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary for image uploads

## Features
- User registration and login
- Secure authentication
- Digital wardrobe management
- Clothing image uploads
- Clothing recommendations
- Saved looks
- User profile

## Run Locally

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## Environment Variables

Configure your backend `.env` file with your MongoDB, JWT and Cloudinary credentials.

**Note:** Never upload `.env` files or secret credentials to GitHub.
